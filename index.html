What is about:blank? (Simple Guide)
Normal Browser Tab
🔗 https://example-site.com

Shows the real website link in the address bar.

about:blank Tab
📄 about:blank

Shows about:blank in the address bar with your chosen tab icon & title!

  1. How it works: Every browser has a built-in empty page called about:blank. This tool opens that blank page and puts your chosen website neatly inside it.
  2. If nothing opens: Your browser blocked the pop-up! Look at the top-right corner of the real address bar, click the small blocked pop-up icon, and pick Always allow.
  3. If a website stays blank: Some big websites block opening inside frames—for those, use Open in a Real Tab instead.
